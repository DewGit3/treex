# Treex

**A lightweight command-line directory tree utility.**

Treex is a command-line utility designed to display directory structures in a readable tree format.

The project aims to provide a simple, lightweight and accessible tool for navigating and inspecting directory hierarchies.

## Features

- Directory structure visualization.
- Lightweight command-line interface.
- Minimal dependencies.
- Simple installation.
- Free and open-source software.

## Installation

Clone the repository:

```
git clone https://github.com/DewGit3/treex.git
```

Navigate to the project directory and follow the installation instructions.

## Usage

Run Treex from your command-line environment:

```
treex
```
